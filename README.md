# AI_LAB_EXPERIMENT3
AI Lab Experiment using Python
Experiment 3: Menu-Driven Student Information Management

Aim:
To implement a menu-driven Python application using functions and modular programming concepts to manage basic student information.

Concepts Used:
- Python dictionaries
- User-defined functions
- Loops
- Conditional statements
- Menu-driven programming

Description:
The program maintains student records using a dictionary. It provides a menu to add, view, search, and delete student records. The program continues running until the user selects the Exit option.

Features:
1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Exit

How to Run:
python experiment3.py

Sample Output:

4. Delete Student
